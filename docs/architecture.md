# Architecture

## Overview

**bitwarden-desktop-next** is a lightweight Rust alternative to the official Bitwarden desktop app (Electron/Angular). It uses the **Iced 0.14** GUI framework with an Elm-style architecture.

## Tech Stack

- **Language**: Rust (2024 edition)
- **GUI**: Iced 0.14 (wgpu/tiny-skia rendering, no webview) with `tokio`, `svg`, `advanced` features
- **Menus**: `muda` for native macOS menu bar + optional on Windows/Linux via `DEV_BOTH_MENUS=1`; custom-drawn iced title bar on Windows/Linux
- **Icons**: Bootstrap Icons v1.13.1 (TTF font, codepoints auto-generated by `build.rs`) + Bitwarden Icons (bwi) font
- **Font**: Inter (variable, bundled in `assets/InterVariable.ttf`)
- **Theme**: Custom `AppTheme` type with dark/light palettes, runtime switching
- **Architecture**: Elm pattern — view structs own state, `update()` returns action enums for cross-cutting effects

## State Model

```rust
// Root app — thin dispatcher (11 fields)
struct App {
    state: AppState,
    current_theme: AppTheme,
    login_view: LoginView,
    vault_view: VaultView,
    title_bar: TitleBarState,
    native_menu: Option<NativeMenuHandle>,
    // + fullscreen, maximized, cached_email/server/accounts, menu_attached, window_id
}

// Each view owns its state and handles its own messages
struct LoginView { password_input, show_password, dropdown_open }
struct VaultView { search_query, active_filter, selected_item/id, sidebar_*, pane_state, cached_items, ... }
struct TitleBarState { open_menu, open_submenu }
```

### Action Pattern

Views return action enums from `update()` for cross-cutting effects:
- `LoginAction::Unlock` / `LogOut` / `SwitchUser(uid)`
- `VaultAction::SwitchUser(uid)` / `FocusSearch`
- `TitleBarAction::MenuAction(action)` / `Minimize` / `Maximize` / `Close` / `Drag` / `ResizeEdge`

App processes these actions (screen switch, user mutation, window ops).

## Menu System

Single `MENUS` static drives both custom and native menus:
- **Custom title bar** (Windows/Linux): renders labels, dropdowns, shortcuts, submenus
- **Native muda** (macOS, or `DEV_BOTH_MENUS=1`): `Shortcut::to_accelerator()` adds shortcuts, `NativeMenuHandle` bridges events via `MenuEvent::receiver()`, `sync_native_enabled()` syncs enabled states

## Icon System

- `Icon(char)` / `BwiIcon(char)` — typed wrappers around font codepoints
- `.render(size, color)` → `Element` for general use
- `.input_icon(size, side)` → `text_input::Icon` for TextInput
- Bootstrap Icons auto-generated from CSS by `build.rs`
- BWI codepoints defined manually from official SCSS

## Overlay Pattern

Dropdowns use `components::drop_down::DropDown` (local fork of iced_aw) which uses iced's overlay system for window-level rendering. Custom alignments: `BelowLeft`, `BelowRight`, `AboveRight`.

## Key Dependencies

- `iced = "0.14"` with `tokio`, `svg`, `advanced` features
- `muda = "0.17"` — Native OS menus
- `iced_aw = "0.13"` (default-features = false) — kept as source reference
